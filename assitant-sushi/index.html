Contrôler une fiche et signaler une correction

Dans l’assistant, ouvre un produit puis touche « Valider / remarquer ». Tu peux vérifier le nombre de pièces, leur position, les ingrédients et le code de balance. Enregistre ta remarque, puis utilise « Exporter mes remarques » pour obtenir le fichier à me transmettre dans la conversation.

Les remarques ne sont pas envoyées automatiquement et ne sont pas synchronisées entre appareils. Pour les combos, chaque composant disponible ouvre sa recette; le bouton Retour ramène au combo précédent.

Version de consultation à valider. Les fiches MITO restent la référence. Trois fiches ne sont pas disponibles : onigiri thon 83130, Hand Roll saumon 83562 et Hand Roll crevette 83561. Les codes partagés et les contradictions du guide sont signalés, sans correction inventée. Le mode Lecture est une interface web, pas une application native pour lunettes.
