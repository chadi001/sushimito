# Sushi Assistant — portail de validation GitHub

Ce dossier est le point d'accès GitHub Pages de l'assistant de préparation de sushi MITO. Il n'est **pas** la publication publique des recettes et photographies sous licence MITO.

## Ouvrir l'application

1. Ouvrir `https://chadi001.github.io/sushimito/sushi-assistant/`.
2. Télécharger le fichier **Assitant_Sushi_MITO_Validation.zip** dans la conversation ChatGPT contenant le projet.
3. Dans la page, sélectionner le ZIP (sans le décompresser).
4. Le contenu est chargé **localement** dans le navigateur. L'application devient disponible via les boutons de la page.
5. Pour une autre tablette ou un autre téléphone, charger le ZIP sur cet appareil également.

## Pourquoi un import local ?

Les recettes et photos du guide MITO peuvent être protégées. La publication GitHub Pages est publique; par défaut, ce portail ne rend **aucune fiche ni photographie** accessible dans le dépôt. Les fichiers restent dans le cache local du navigateur de la personne qui les importe.

## Vérifications obligatoires

- La boîte montrée doit contenir exactement le nombre et l'emplacement de morceaux spécifiés dans la fiche.
- Les condiments, sauces, gingembre, wasabi et logo MITO ne doivent pas être inventés ou supprimés.
- Les codes de balance sont ceux des fiches consultées, **pas une garantie de validité opérationnelle en IGA**; un code douteux doit être confirmé.
- Les photos sources priment sur les images de synthèse.
